# User Service - System Integration - Sistem Penyewaan Peralatan Outdoor Terdistribusi

Layanan ini merupakan bagian dari Sistem Penyewaan Peralatan Outdoor Terdistribusi yang berfungsi sebagai *Provider* dan bertanggung jawab untuk mengelola data pribadi users.

## Fitur

Layanan ini memiliki *13 endpoint* yang berkaitan dengan data pribadi member.
